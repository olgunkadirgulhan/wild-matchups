Wild Matchups

Wild Matchups publishes short animated videos that compare wild animals by real statistics: top speed, weight, bite force and body length. Every result is decided "on paper" from the numbers; no real fights are shown or claimed.

This site describes the publishing tool behind the Wild Matchups YouTube channel. The tool renders our own original animations (animal silhouettes from PhyloPic, public domain) and uploads them to our own channel using the YouTube Data API. It does not access any other user's data.
