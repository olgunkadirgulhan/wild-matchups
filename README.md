# Wild Matchups

Animated Shorts and long videos that compare wild animals by real statistics (top speed, weight, bite force).
"On paper" only: no fights are shown or claimed. Silhouettes from PhyloPic (public domain / CC0; CC BY credited in descriptions).

- `wild.py` — 23 Short formats + 16-animal tournament (16:9)
- `.github/workflows/videos.yml` — scheduled production (needs `vars.LIVE=true` and YouTube secrets)
